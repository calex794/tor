# S020 / P0 #486 — матрица возрастного доступа TOR

Текущая матрица — проверяемая карта существующих тестов, а не разрешение запускать возрастной редактор на рабочем сервере. Контроль наличия кода и подключённых проверок **не заменяет реальные испытания** PostgreSQL, HTTP, Chromium и MinIO.

## Обязательные границы

| Граница | Действующее правило | Исполняемая проверка |
| --- | --- | --- |
| Гость, обычный читатель, карточка и каталог | Анонимно — только \`basic\`; неизвестный NULL закрыт; для 18+ нужен активный \`adult_enabled\`, для 21+ — самостоятельный живой \`pro_adult\`-грант. | \`actor_catalog_age_pg\`, \`shadow_age_visibility_pg\`, \`s020_age_editor_http_pg\` |
| S019: поиск похожих названий и публичные связанные книги | Скрытые, 18+/21+, NULL не выдаются через анонимные подсказки. Управление связями владельцем проверяется отдельно, без случайного запрета взрослых книг. | \`title_suggestions_pg\`, \`public_related_http_pg\` |
| Бесплатный текст, оглавление, платный предварительный просмотр | Авторизация повторяется у выдающего SQL, а изменение уровня книги немедленно меняет ответ. Оплаченный текст не попадает в бесплатный ответ. | \`s020_age_editor_http_pg\`, \`s020_age_editor_browser_pg\` |
| Личная библиотека, сохранённые главы, рейтинг F-05 | Старое сохранение не равно возрастному допуску: после отзыва скрывается название и запрещено новое изменение рейтинга. История не удаляется. | \`s020_age_editor_http_pg\`, \`slices_pg f_05_\` |
| Рекомендации, оценки и уведомления | Публичные рекомендации ограничены уровнем, частные данные проверяются повторно; уведомление о новой главе само по себе не даёт права чтения. | \`book_stars_pg\`, \`feedback_pg\`, проверка SQL \`notification_read_policy\` |
| Купленная зашифрованная V1 и сохранённые покупки | Наличие чека/покупки не обходит возраст; при отзыве прекращается выдача нового содержимого, существующие финансовые факты и номер редакции сохраняются. | \`paid_grants_s3_pg/s020_paid_completion_age.rs\`, \`paid_grants_http_pg\` |
| Подписной Layer, зашифрованный текст, иллюстрации | Прямое получение новых подписанных ссылок и обёрток ключа требует актуального допуска. В тесте отдельный покупатель, чтобы 429 от ограничения запросов не имитировал отказ по возрасту. | \`paid_grants_s3_pg\` и обязательный \`paid-private-e2e\` |
| Администратор и модератор | Привилегированный просмотр — отдельная проверяемая роль администратора, а не обычного модератора или произвольного владельца книги. | \`paid_grants_http_pg/s020_admin_age.rs\`, \`s065_role_matrix.rs\`, \`s065_admin_browser.rs\` |
| Редактор уровня | Только собственные действующие настройки, реальный переход \`basic → adult → pro_adult\`, Origin/CSRF, отказ на удалённых книгах. Включается явным флагом, по умолчанию закрыт. | \`s020_age_editor_http_pg\`, \`s020_age_editor_browser_pg\`, \`test_s020_age_editor_survival.py\` |

## Как принимать

1. Проверить точный SHA и обязательные запуски \`.github/workflows/tor-integration.yml\`, \`tor-pg-runtime.yml\`, \`rules.yml\`; одних зелёных отметок недостаточно, если старый merge удалил тесты.
2. Убедиться, что PostgreSQL/HTTP, браузер и платный MinIO действительно выполнили указанные отрицательные проверки, особенно после отзыва 18+/21+ и при \`access_level IS NULL\`.
3. Проверить независимость прав покупателя, сохранённой версии и права чтения, а также отдельную роль администратора.
4. Сверить параллельные изменения интерфейсов, прежде всего [S016: рекомендации книг друзьям, PR №730](https://github.com/calex794/tor/pull/730), и Layer TOC [PR №729](https://github.com/calex794/tor/pull/729). Не объявлять закрытым #486 по устаревшему исходному тексту.
5. После завершения общей матрицы и испытаний объединённой ветки отдельно решить включение \`TOR_S020_ACCESS_EDITOR_ENABLED\` на тестовом сервере. Рабочий сервер и постоянная база в рамках этой задачи не меняются.
