# Нулевой контракт (статус: подготовка)

Прежде чем параллельная разработка начнёт изменять общие типы, интегратор фиксирует:
1. ID: UserId, BookId, ChapterId, ChapterVersionId, PurchaseId и внешние ID.
2. Права: автор/редактор vs читатель/оплаченная версия; при неизвестном доступе отказ.
3. HTTP: пути, роли, запрос/ответ, ошибки, границы с единицами, курсорная пагинация, версия данных.
4. PostgreSQL: у каждого набора таблиц один владелец, все миграции централизованы; покупка/журнал/право атомарны.
5. События: публикация/оплата/уведомление с ID, версией, защитой повтора и долговечным outbox.
6. Ограничения файлов: байты и MIME медиа, символы текста главы, размер импорт-пакетов; не выдавать предлагаемые лимиты за принятые.
7. Проверки: базовые положительные, отрицательные, конкурентные и восстановление после перезапуска/отказа.

Опорная [спецификация v0.2](https://app.notion.com/p/40432a84beec81c49bbad75e88ff6989). Этот документ не объявляет контракт API сформированным: OpenAPI и миграции следует добавить из проверенной Rust основы с адаптацией к `tor`.
