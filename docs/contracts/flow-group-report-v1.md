# FLOW — сравнение жанров и тегов

## Пользовательский путь

Администратор открывает личный кабинет → «Аудитория» → «Жанры и теги»,
выбирает вид группы и период, сравнивает направления и переходит к книгам
выбранной группы. Период сохраняется при переходе к подробному
[отчёту по книгам](flow-book-report-v1.md).

Это отдельный путь внутри FLOW-05 из
[существующей спецификации](https://app.notion.com/p/41132a84beec81c08561f999c74144fb).
Его приёмка не закрывает всю FLOW-05 или линию FLOW. Возвращаемость
D1/D7/D30, уникальные люди и полный путь посещения остаются отдельно.
Нового сбора, личных идентификаторов и миграций этот отчёт не вводит.

## Маршруты и параметры

`GET /admin/audience/groups` принимает только следующие параметры:

| Параметр | Значение |
| --- | --- |
| `kind` | `genres` или `tags`; по умолчанию `genres` |
| `days` | `1`, `7`, `30` или `90`; по умолчанию `7` |
| `after` | Непустое нормализованное имя последней группы предыдущей страницы |

Группы без метки идут первыми, затем названия в порядке PostgreSQL
`COLLATE "C"`. На странице не больше 20 групп. Следующая страница сохраняет
вид группы и период; новая отправка формы начинает список сначала.
Ограничение страницы не обрезает исходные дневные строки или сводку.

Для перехода к книгам группа передаётся в `genre` или `tag` маршрута
`/admin/audience/books`. «Без жанра» использует `without_genre=true`,
«Без тега» — `without_tag=true`. Эти булевы параметры принимают только
`true` / `false`, по умолчанию `false`. Признак отсутствия метки вместе
с непустым значением того же фильтра — ошибка 400. Одновременные ограничения
по разным видам меток применяются вместе. Пустой строковый фильтр по-прежнему
означает отсутствие ограничения и не подменяет группу «Без…».

Названия нормализуются теми же правилами, что фильтры книг: пробельные
последовательности схлопываются, регистр понижается, не больше 40 символов
после нормализации и 512 исходных байт; управляющие символы запрещены.
Пустой `after` не является курсором. Значения в ссылках кодируются как UTF-8
параметры URL, а отображаемый текст экранируется для HTML. Неизвестные,
повторные и неверные параметры отвергаются после проверки доступа.

## Каталог и расчёт

Область — нынешнее F-представление `rec_public_books`: публичные,
активные книги уровня `basic` для аудитории `general`. Закрытые, скрытые,
удалённые, ожидающие удаления, удержанные и возрастные книги не входят
в названия групп, книжные количества и числовые итоги.

Используются **нынешние** жанры и теги. Изменение метки переносит показатели
книги к её новому направлению; историческая принадлежность не восстанавливается.
Книга входит один раз в каждое своё значение выбранного вида, даже если
массив содержит повтор метки. Жанры с тегами не перемножаются. Книга без
меток выбранного вида входит в отдельную группу «Без жанра» / «Без тега».

Группы могут пересекаться. Их числа нельзя суммировать как уникальные
книги или людей. Общая сводка считает каждую доступную книгу один раз,
независимо от количества её меток и текущей страницы групп. Количество
доступных книг определяется текущим каталогом и одинаково для обоих
периодов, а состояния наблюдения считаются отдельно для каждого периода.

Для группы показаны количество доступных книг и следующие данные текущего
и предыдущего равного периода:

- Выданные ссылки каталога и поиска — Organic `issued`, отдельно от
  наблюдаемых показов рекомендаций REC `impressions`.
- Учтённые переходы — Organic `clicks` и REC `paired_clicks + unpaired_clicks`.
- Открытия книги — сохранённые `book_opens` трёх внутренних источников.
- Первые чтения книги — `starts`, включая неизвестный источник.
- Число книг в состояниях «Нет сохранённых наблюдений», «Есть наблюдения,
  первых чтений нет» и «Есть первые чтения».

Смысл показателей и трёх состояний совпадает с
[отчётом по книгам](flow-book-report-v1.md). В группе без положительных
наблюдений остаются её книги и неизвестные измерения. Отсутствие сохранённого
факта не доказывает отсутствия показов или интереса.

Используются полные дневные F-итоги обоих периодов, а не ограниченная
служебная выдача `quality()` / `organic_quality()`. Текущий период:
`[tomorrow-days, tomorrow)`, предыдущий: `[tomorrow-2*days, tomorrow-days)`
по календарю UTC. Сегодня ещё не закончился. Правила дат выдачи и первого
чтения, повторов, согласия и хранения прежние: сырые факты 30 дней,
обезличенные дневные итоги 180 дней.

Нет измерения — «Нет данных», измеренный ноль — `0`. Историческая REC-строка
с `book_opens IS NULL` делает открытия соответствующей книги, её групп
и общей сводки за этот период неизвестными; независимые группы сохраняют
известные открытия. Другие показатели не теряются. Разница выводится
только между известными значениями. Проценты строгой воронки не выводятся.

При неизменных исходных данных строка группы и сводка её книжной
детализации совпадают. Оба отчёта используют общий расчёт по книгам.
Разные HTTP-запросы могут увидеть последующую обработку событий или
изменение карточек; время снимка и состояние обработки показаны на странице.

## Доступ и отказ

Каждый запрос сначала проверяет действующую A-сессию и роль администратора.
Роль проверяется заново, её отзыв закрывает следующий запрос. Вся операция
имеет общий срок 950 мс. F читает каталог, оба периода и состояние обработки
в одной транзакции `REPEATABLE READ READ ONLY`, `statement_timeout=750ms`.
При ошибке или превышении срока — 503 с явным состоянием недоступности;
несуществующие нули вместо неполученных данных не показываются.

Успехи и ошибки имеют `no-store`, `noindex, nofollow` и строгую CSP.
Страница работает без JavaScript. Свежесть подтверждения обработчика
за последние 30 секунд и ожидающие пересчёта группы показаны отдельно;
свежесть не доказывает полноту охвата посетителей.

В RIL зарегистрирован только точный административный GET. Никаких общих
допусков для `/admin/audience/*`, изменяющих методов или выгрузок нет.

## Приёмка

На одноразовой мигрированной PostgreSQL `tor_ci`:

```bash
cargo test -p tor-recommendations --test audience_groups_pg -- --ignored --test-threads=1
cargo test -p tor-web --test audience_groups_http_pg -- --ignored --test-threads=1
```

Проверяются несколько жанров и тегов, повторы меток, отсутствие перемножения,
более 100 дневных строк, полные суммы и несколько страниц, все периоды,
смена метаданных, скрытие книги, группы без меток и наблюдений, измеренный
ноль, старые неизвестные открытия только в соответствующих группах.
HTTP проверяет доступ, его отзыв, ошибочные параметры, специальные символы,
переходы к детализации, заголовки, ограниченное ожидание и восстановление.

`tools/audience_groups_pg_browser.cjs` проходит реальный путь «Аудитория →
жанры/теги → книги группы» в Chromium на ширинах 390 и 1440, сравнивает
числа с детализацией и проверяет отзыв роли. Положительные показатели
поступают через действующие пользовательские действия и обработчик,
а не подставляются готовыми в таблицы итогов. Снимки просматриваются.
Существующие проверки книжного отчёта продолжают выполняться.

Наличие проверок не является результатом их выполнения. Фактические SHA,
PostgreSQL/HTTP/браузерные результаты, CI и итог основной ветки фиксируются
в существующем Notion. Развёртывание сервера этим путём не выполняется.
