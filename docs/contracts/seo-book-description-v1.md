# SEO-02a — реальные описания книг и публичные данные

Этот PR добавляет полный путь «создать книгу с аннотацией → PostgreSQL →
публичная карточка с аннотацией», не включая SEO-индексацию.

- B: поле description, ≤4000 Unicode-символов, проверка входа; для старых
  книг пустая строка. Дополнительная версия SQLx 202610280008.
- Принцип старых команд: пустое описание не меняет старый отпечаток
  идемпотентности; непустое включено с отдельной меткой в хеш.
- H: автор вводит описание только в своей форме с CSRF/Origin. Объём
  тела формы 64 КиБ (кодирование Unicode может занимать больше исходного текста).
  Публичная карточка показывает аннотацию с экранированием, настоящих
  автора и жанры, и берёт meta description из этих же данных.
  Если описание отсутствует, не выдумывать содержание книги.
- C: public_book_page проверяет опубликованность, admin_hold, is_deleted
  в том же SQL, что выбирает метаданные; без чтения текста платных глав.
- Проверка: B unit/PG на границы, сохранение, повтор; C PG на hidden/hold;
  H unit на HTML и метаописание, существующие HTTP/Chromium тесты.

**Блокер миграции:** версия 202610280007 зарезервирована за
[Shadow PR №170](https://github.com/calex794/tor/pull/170). Не применять
008 в рабочей базе до согласования и принятия 007. Не сливать этот PR
до зелёного итогового CI и порядка миграций; VPS не менять.

Редактирование описания уже существующей книги — отдельный SEO-02b с
CSRF, владельцем и RIL; не считать его выполненным этим PR.
Следующий SEO-03 определяет постоянный URL, SEO-04 — общий
canonical/robots/OG/JSON-LD.

## SEO-02b (отдельная ветка)

Добавлены операторски проверяемые `GET/POST /me/books/{id}/description`:
форма только для владельца, CSRF/Origin, жёсткая проверка owner_user_id,
блокировок и удаления; RIL-08 реестр охраны и отрицательные проверки.
Проверка `seo_description_pg` расширена сценарием другого автора,
запретом изменения блокированной книги и недопущением HTML-инъекции.
Отдельные права на платное чтение не затрагиваются.
