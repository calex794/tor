# TOR / ВНИМАНИЕ — единый план управляемого внимания и перекрёстных продаж (ATTN)

**Единый канонический пошаговый план REC/ATTN:** [рекомендации, измерение, настраиваемые доли и единая административная панель](rec-attention-unified-plan.md). Этот файл сохраняется как прежняя детализация ATTN и исторические доказательства; в конфликтующих правилах приоритет у единого плана. С 13.11.2026 «автор» — владелец книги `books.owner_user_id`, нет обязательной модели томов/серий, доли в органической полке настраиваются администратором: 50/40/10 = автор / команда / **другие авторы**, без команды 70/30 = автор / **другие авторы**. Исторический внутренний ключ `site` не обозначает отдельную категорию и подлежит совместимому переименованию при реализации. Смешанная редакционная/органическая полка #857 пока Draft и не равна принятому main.

**Источник решений:** [рекламные места и полка 50/40/10](https://app.notion.com/p/40432a84beec81378f36e7e103841e6c), [неперсональная REC/FLOW](https://app.notion.com/p/41132a84beec81c08561f999c74144fb), [редакционное продвижение](../contracts/editorial-promotion-v1.md), [REC-01…14](recommendations-execution-contract.md). Этот план конкретизирует существующую линию F и не создаёт ещё одну рекламную/платёжную подсистему.

## Цель и измеримое обещание

Увеличить **дополнительное осмысленное чтение и денежный вклад собственных книг TOR на единицу доступного внимания**, не ухудшая продолжение исходной книги. Клики сами по себе не являются результатом. Пока нет production-эксперимента и валидной связи с покупками, нельзя заявлять рост выручки или прогноз конверсии.

На первом этапе TOR — собственное цифровое издательство: **без** рекламных счетов сторонних авторов, платных Chapter Ads, рекламного escrow, publisher settlement, индивидуальной истории просмотра, дополнительного REC/FLOW согласия, рекламных вставок в литературный текст, раскрытия платных глав и изменения прав.

## Нормативные правила

1. **Единое физическое место** после **текста и навигации** опубликованной бесплатной главы: сначала активное разрешённое редакционное размещение; при его отсутствии одна органическая полка из 4–5 книг. Никаких двух блоков параллельно.
2. **REC-F 50/40/10:** другие произведения владельца исходной книги / официальные активные сокомандники / остальные произведения сайта. Без командных книг — **70/0/30**, недостаток любой категории заполняется другими доступными; пропорции проверяются на множестве выдач, не на каждой полке. Исключить текущую книгу, повторы, личные скрытия и неподходящий по возрасту/состоянию контент.
3. **Сначала допустимость, потом ранжирование:** canonical текущая discoverability, права зрителя, 18+/21+, admin hold, deletion/pending deletion, editor activation и расписание проверяются на сервере. При сбое необязательного источника основной текст доступен.
4. **Не отвлекать от оплаты текущей серии:** платные и приватные читатели не получают бесплатную органическую полку. Не создавать новую точку прерывания непосредственно в момент покупки.
5. **Контекст до персонального слежения:** жанры/теги исходной книги и явные оценки читателя; без истории его показов и переходов. Новые семантические признаки главы можно вычислять офлайн при публикации как metadata без персональных событий; до эксперимента не использовать их как доказательство коммерческого успеха.
6. **Один договор наблюдений:** серверная подписанная квитанция FLOW, наблюдаемая видимость карточки, клик и независимое подтверждённое чтение — разные факты. Без индивидуального профиля нельзя достоверно атрибутировать покупку конкретному показу; не выводить ложный ROI.

### Правила выкладки

- Пакеты должны быть небольшими PR поверх актуального `main`; изменение общего HTTP/RIL, контрактов или SQL координировать с I.
- Каждый PR: точный исходный/целевой контракт, отрицательные проверки, реальный PostgreSQL и браузер, если есть изменённый пользовательский путь; обязательные GitHub Actions на exact head и post-merge.
- Никакого автоматического deploy, production-миграций или включения флагов. Единственный допустимый выпуск — ручной по отдельно подтверждённому SHA согласно `AGENTS.md`.
