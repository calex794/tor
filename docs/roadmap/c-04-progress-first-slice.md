# C-04 — чтение с продолжением, этап 1 (без HTTP)

Перенесены из `bokarust@d11b27b` строго типизированные курсоры UTF-16 и `PgReadingProgress` в собственный feature-модуль `tor-reading`. Данные доступны **только по user_id из проверенной сессии**, не по параметру клиента. Наличие сохранённого положения никогда не предоставляет право чтения платной или закрытой главы.

PostgreSQL-репозиторий проверяет актуальную опубликованную версию, состояние книги/главы (draft/hold/deleted/embargo), запрещает запись прогресса устаревшей версии, не откатывает позицию назад при повторном/задержанном запросе. Реальные PG18 интеграционные тесты добавлены в CI.

**Ограничение:** HTTP `/me/library`, кнопка «Продолжить чтение» и авторизованная страница сохранения прогресса в этот PR не включены. Следующий PR должен связать `PgReadingProgress` с проверкой сессии и CSRF, добавить интерфейс 390/1440 px и сквозную браузерную приёмку. Ни один autosave-обработчик не должен обходить CSRF/ACL.

## C-04/C-05 — сохранение позиции с пользовательского экрана

Публичный `/reader/{id}` остаётся полностью бесплатным и анонимным. Приватный `GET /read/{id}` требует подтверждённую PostgreSQL-сессию, показывает максимум 200 детерминированных фрагментов и кнопку «Сохранить место здесь» для каждого из них. `POST /read/{id}/place` использует Origin, двойной CSRF-cookie, опубликованную актуальную версию, границы UTF-16/фрагментов и SQL ACL. `/me/library` показывает ссылку `/read/{id}#p-N`; при смене версии позиция не выдумывается. Нет JavaScript/автосохранения, зато работают обычные формы и клавиатура. Тесты: PG18, Chromium 390/1440 px и отсутствие горизонтального переполнения. Эта версия не поддерживает платный прогресс.
