# tor — BookaRust

Единый рабочий репозиторий новой реализации NEwBOO на Rust + PostgreSQL.

**Статус:** в `main` есть лишь демонстрационный публичный каталог с данными в памяти, **не** полноценный сайт с PostgreSQL/главами/платежами. Переносить действующий код из [calex794/bokarust](https://github.com/calex794/bokarust), а не начинать заново. [HeisLuka/newboo](https://github.com/HeisLuka/newboo) — эталон поведения, без копирования закрытых исходников в публичный репозиторий.

## Цель

Один сайт, полностью соответствующий подтверждённому функционалу NEwBOO. Девять направлений разработки работают параллельно и часто вливают небольшие проверенные изменения в защищённую `main`. Полнота доказывается пользовательскими сценариями, а не числом файлов и PR.

- **Архитектура:** один Axum / Tokio сервер и PostgreSQL; каждая предметная область — собственный Cargo-пакет с `api → services → repositories`, а также `schemas`, `domain` и тестами. Общие контракты и подключение модулей — отдельно. [Обязательные правила](docs/architecture/feature-first.md), [реестр владельцев](architecture/modules.toml).
- **Интерфейс на запуск:** серверный HTML и CSS из Rust/Axum; небольшие улучшения браузерного поведения там, где нужны. Leptos/WASM — после измерений, FrontRust — независимый эксперимент и не блокирует запуск.
- **Сборка и показ:** GitHub Actions проверяет изменения; только прошедший проверки `main` допускается к развертыванию на испытательном сервере. Домен, сервер, SSH и PostgreSQL настраиваются через секреты GitHub и серверную конфигурацию, не в репозитории.
- **Исполняемый роадмап:** [117 задач по девяти линиям — конкретные файлы, маршруты, PostgreSQL и тесты](docs/roadmap/README.md); [карта 69 сценариев](docs/roadmap/scenarios.tsv). [Исторические страницы Tela Wiki](https://telawiki.com/spaces/430/pages/7725/bookarust-main-100-newboo).
- **Исходная спецификация:** [Notion v0.2](https://app.notion.com/p/40432a84beec81c49bbad75e88ff6989).
- **Функциональное покрытие:** [69 сценариев](https://app.notion.com/p/40432a84beec8160b18ae1ef4bade732) и [матрица фактического соответствия](https://app.notion.com/p/970f1eab10e041489e285725a697b513). Реальная полнота по эталону должна быть проверена; отдельные сценарии ранее исключены, конфликт с буквальным «100%» открыт.

## Порядок старта

1. [AGENTS.md](AGENTS.md) и [docs/development.md](docs/development.md) — обязательные правила для исполнителей.
2. [docs/contracts/README.md](docs/contracts/README.md) — общие договорённости и границы, сначала без массовой переписи кода.
3. Перенос рабочего Rust-каркаса и его тестов из `bokarust` с точной ссылкой на исходный SHA.
4. Первая настоящая работающая цепочка: каталог → книга → опубликованная глава → PostgreSQL → браузер.
5. Девять веток/коротких PR → проверенный `main` → испытательный сервер.

**Готово** означает наличие кода в `main`, проходящие проверки с PostgreSQL и браузером, отсутствие утечек платного/закрытого контента и ссылку на исходный сценарий. Ни документ, ни зелёная сборка без полного сценария этого статуса не дают.

## Первая исполнимая версия S0 (кандидат в PR)

В `crates/books` находится функциональный пакет каталога с переносом проверенных доменных правил из `bokarust`; `crates/web` выводит реальные HTML-страницы. На текущем этапе это **публичный демонстрационный каталог** без регистрации, глав, денег и постоянного хранения. Полная инструкция: [docs/architecture/s0-demo.md](docs/architecture/s0-demo.md). GitHub Actions собирает релиз **вне VPS**.
